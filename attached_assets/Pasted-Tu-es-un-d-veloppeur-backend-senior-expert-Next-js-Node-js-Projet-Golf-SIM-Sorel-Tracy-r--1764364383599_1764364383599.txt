Tu es un développeur backend senior, expert Next.js/Node.js.  
Projet : « Golf SIM Sorel-Tracy – réservation + synchronisation avec Google Calendar ».  

Stack : Next.js (API routes) + Node.js + base de données simple (SQLite ou fichier JSON ou autre) + Google Calendar API via la librairie officielle `googleapis`.  

### Fonctionnalités backend à générer :

1. Route POST `/api/book` — pour recevoir les données d’un formulaire de réservation :  
   - Données reçues : nom complet, courriel, téléphone, date, heure de début, durée (en heures), nombre de joueurs, type de bay, remarques.  
   - Valider les champs requis (nom, courriel, date, heure, type de bay, etc.).  
   - Vérifier la **disponibilité** du bay demandé à cette date + heure + durée — c.-à-d. s’assurer qu’il n’y a pas déjà une réservation existante qui chevauche (dans la base de données).  
   - Si indisponible → renvoyer erreur JSON : `{ ok: false, message: "Bay non disponible" }`.  

2. Si bay disponible → créer la réservation :  
   - Inscrire la réservation dans la base de données (date, heure début, heure fin, nom, courriel, type bay, joueurs, remarques, id_event_calendar = null pour l’instant).  

3. Créer un événement dans Google Calendar :  
   - Utiliser la librairie `googleapis` avec un compte de service (ou OAuth selon ce que tu préfères), authentifié via des **variables d’environnement** : `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `REFRESH_TOKEN` ou credentials JSON selon méthode, et `CALENDAR_ID`. :contentReference[oaicite:1]{index=1}  
   - Construire l’événement avec ces propriétés :  
       • `start`: dateTime = date + heure début  
       • `end`: dateTime = date + heure début + durée  
       • `summary`: par exemple `"Réservation Golf SIM – [Nom] – [Bay]"`  
       • `description`: inclure le nombre de joueurs, téléphone, remarques, lien vers contact, etc.  
   - Appeler `calendar.events.insert({ calendarId, event: { ... } })` pour créer l’événement. :contentReference[oaicite:2]{index=2}  
   - Récupérer l’`id` de l’événement renvoyé et l’enregistrer dans la base de données (mise à jour de la réservation).  

4. Retour de l’API : renvoyer un JSON `{ ok: true, reservation: {...}, calendarEventId: ... }` à l’utilisateur / frontend.  

5. Gérer les erreurs : si l’appel Google Calendar échoue, supprimer la réservation dans la base de données (rollback), et renvoyer une erreur — pour éviter d’avoir des réservations “orphelines”.  

6. Sécurité : les clés / credentials Google doivent être stockées dans des variables d’environnement — ne jamais les exposer côté client.  

7. Documentation / README :  
   - Expliquer comment configurer un projet dans Google Cloud, activer l’API Google Calendar, créer un compte de service ou OAuth, partager le calendrier avec le compte de service si besoin, obtenir `CALENDAR_ID`. :contentReference[oaicite:3]{index=3}  
   - Expliquer comment configurer les variables d'environnement dans Next.js / sur l’hébergeur (Replit ou autre).  
   - Instructions pour lancer le serveur localement, tester la route, simuler une réservation, vérifier que l’événement apparaît dans Google Calendar.
